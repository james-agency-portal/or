Ad comments

See and moderate comments on every Facebook and Instagram ad across all your ad accounts, in one place.

The token stays in this browser only. Nothing is sent anywhere except to Meta.

How to get a token that never expires
  1. Go to Business Settings → System users and add one (role: Admin).
  2. Assign assets: every ad account (Manage) and every Page (Full control).
  3. Generate token. Pick an app (or create one: Business type, any name). Tick: ads_read ads_management pages_read_engagement pages_manage_engagement pages_show_list instagram_basic instagram_manage_comments. Expiry: Never.
  4. Paste it above.

For a quick test, a user token from Graph API Explorer with the same permissions also works, but expires in about two hours.
